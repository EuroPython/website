Interesting in using your Python skills to make physical devices,
such as sensors, control systems, robots or similar?
MicroPython is an implementation of Python 3 that runs on low-cost microcontrollers
and has a mature ecosystem that makes programming hardware fun and productive.

In this sprint we will work on MicroPython related things, such as:

- Making demos/examples for/using existing libraries
- Creating new libraries for MicroPython

Open for people who have no prior experience with MicroPython!
We have 5 hardware units running MicroPython that people can borrow for the sprint (Raspberry Pi Pico W RP2040).

You can also run MicroPython on your PC, as well as in the browser.
