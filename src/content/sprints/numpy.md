NumPy is the premier library for numerical computing on CPUs in Python. If you
are interested in working on NumPy internals or somehow improving NumPy, please
join us! NumPy is written in C, so people with prior knowledge of the CPython C
API and C programming will be able to get going on NumPy internals more easily
than those without.

If you do not have C skills, there are issues that require only Python. We also
have a number of documentation issues that need to be fixed, so people who enjoy
working with Sphinx projects can also help out.
