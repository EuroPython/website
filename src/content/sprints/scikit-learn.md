scikit-learn is one of the most widely used open-source machine learning libraries
for Python, providing simple and efficient tools for data analysis and modeling.

This sprint is open to contributors of all experience levels — whether you want
to fix bugs, improve documentation, write tests, or work on new features. No prior
contribution experience is required. Come with your laptop, a working Python
environment, and curiosity!

The contributing guideline is available at the following URL:
https://scikit-learn.org/stable/developers/contributing.html
