We build the database developers love to use. We're giving it to them with the world's first graph-relational database: the maintainability of a strict schema paired with the ability to easily link objects.

With a decade of contributions to the Python ecosystem, including uvloop and asyncpg libraries, we understand the frustrations with traditional ORMs and databases. Our solution removes friction between code and databases.

New Gel-Python integration features include first-class FastAPI support with API generation and schema migrations, a type-safe data API with Pydantic integration, integrated authentication and AI capabilities, and seamless local and cloud development tools.

Stop compromising between powerful features and a great developer experience. With Gel, you get both.
